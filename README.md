🛡️ What is PC DocDefender?

The name PC DocDefender is inspired by the image of a "doctor and computer protector". The goal of the project is to help users check the status of the system, monitor security and assist in identifying suspicious files in the same application while still trying to ensure that the machine consumes the least amount of resources and is suitable for everyone.

🔍 Available features

1. System Diagnostics

· Displays basic computer information.

· Monitor CPU and RAM usage.

· Check the disk space and some system information.

2. Microsoft Defender Integration — Tích hợp Microsoft Defender

· Check the real-time protection status and security signature information when Windows provides the corresponding data.

· Displays security information and retrievable detection records.

· Support users to open Windows Security for further checking.

3. Custom SHA-256 Scanner — Private hash scanner

· Scan a file or folder by calculating a SHA-256 hash.

· Match the hash with the identification data provided to the scanner.

· Supports multi-file inspection and processing of scan results according to the capabilities of the current version.

4. Security Center & Threat Monitor — Security Monitoring

· Summarize some information about the security status of the system.

· Displays the results and findings that the app can collect.

· Supports viewing the system status through the dashboard and reports.

5. Reports and history

· Export diagnostic or security reports according to deployed functions.

· Help users review results and related information.

🧪 Why am I making the beta public?

I'd like the community to help test the features that are available, especially the accuracy of the scans, the integration of Microsoft Defender, performance, and the bugs that can be reproducible on different Windows configurations.

I know that using AI to code may cause some people to disagree with the way I do it, but I still use it in a purposeful and logical way.

⚠️ Things to know

· A NO MATCH result does not mean that the file is definitely safe.

· The SHA-256 scanner only recognizes the hashes contained in the reference data.

· Displaying Microsoft Defender status doesn't mean that PC DocDefender has detected every threat on its own.

· PC DocDefender is still in development and does not replace Microsoft Defender or dedicated security solutions.

Features such as enhanced YARA, larger-scale identity databases, garbage cleaning, and system optimization will only be introduced as official features when they are actually implemented and tested.
